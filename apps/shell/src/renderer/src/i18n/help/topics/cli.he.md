# שורת פקודה וסוכנים

כל התקנה כוללת פקודת `teleoffice` שמנהלת את אותם מנועים שהחלון משתמש בהם — אותם מנתחים, אותו כותב, אותו מרונדר. קובץ שהאפליקציה שומרת וקובץ שהפקודה כותבת הם אותו קובץ, ובדיקה שחלונית ה-AI של האפליקציה עוברת היא בדיקה שגם הפקודה עוברת.

```sh
teleoffice --help          # every command
teleoffice guide slides    # the op reference, for writing your own
```

זה כל הממשק במסך אחד — כל פקודה עם שורה שמסבירה מה היא עושה, ואז האפשרויות הגלובליות וקודי היציאה:

![הפלט האמיתי של teleoffice --help: כותרת הגרסה, כל פקודה עם תיאור של שורה אחת, והאפשרויות הגלובליות וקודי היציאה](img/cli.png)

## קבלת הפקודה

‏macOS ו-Windows מגיעים עמה בתוך חבילת האפליקציה. כדי להשתמש בה לפי השם, הריצו פעם אחת `teleoffice install-cli`: היא יוצרת קישור סמבולי לקובץ ההפעלה המצורף אל `/usr/local/bin`, או אל `PATH` של המשתמש שלכם ב-Windows.

## הפקודות שכדאי להכיר

| פקודה             | מה היא עושה                                                                                                                                                             |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `open`            | פותחת מסמך באפליקציה; מפעילה את האפליקציה אם היא לא רצה.                                                                                                                |
| `selection`       | מה שהמשתמש בחר בקובץ הזה עכשיו, כל עוד האפליקציה רצה — זו ההצבעה על ״זה״ / ״כאן״. לוקחת טווח בלוקים, טווח בגיליון, אלמנטים בשקופית או עמוד, בהתאם לעורך שבו נמצא הקובץ. |
| `convert`         | ממירה בין פורמטים באמצעות המנועים של האפליקציה עצמה.                                                                                                                    |
| `create`          | יוצרת מסמך מתוכן מובנה.                                                                                                                                                 |
| `render`          | PNG אחד לכל עמוד, לפי הפריסה של המרונדר.                                                                                                                                |
| `pdf`             | קוראת את שכבת הטקסט של PDF עמוד אחר עמוד, בלי תהליך של האפליקציה.                                                                                                       |
| `info`            | מטא-נתונים ותקציר מבנה של מסמך.                                                                                                                                         |
| `search`          | חיפוש ברשת או בתמונות דרך הספק המוגדר באפליקציה.                                                                                                                        |
| `image` / `media` | יוצרת תמונה, או מתארת קובץ תמונה, וידאו או שמע ועונה עליו שאלות.                                                                                                        |
| `merge`           | ממלאת מציידי מקום `{{key}}` בתבנית `.docx`, `.pptx` או `.xlsx`.                                                                                                         |
| `capabilities`    | מדווחת אילו יכולות ענן מוגדרות במחשב הזה.                                                                                                                               |
| `guide`           | מפניית הפעולות ומדריכי העיצוב, נוצרות מאותם הגדרות שמולן המבצע מאמת — ולכן היא לא יכולה לסטות ממה ש-`apply` מקבל. `--json` מחזיר אותה עם הסכמה של כל פעולה.             |
| `install-cli`     | מציבה את `teleoffice` ב-`PATH`.                                                                                                                                         |
| `skill`           | מפרטת את סוכני התכנון שנמצאו במחשב הזה ומתקינה בהם או מעדכנת את המיומנות של TeleOffice.                                                                                 |
| `mcp`             | מגישה כל פקודה ככלי ב- Model Context Protocol. ראו **חיבור סוכן תכנון**.                                                                                                |

## עריכה: מסמכים, גיליונות, מצגות

‏`teleoffice docs`, ‏`teleoffice sheet` ו-`teleoffice slides` קוראות ועורכות דרך אותו נתיב כתיבה שהאפליקציה עצמה משתמשת בו, והן חולקות מילון אחד: **פעולה** (op) היא עריכה בודדת, ו**מפרט** (spec) הוא רשימת פעולות המיושמות לפי הסדר.

```sh
teleoffice sheet read report.xlsx
teleoffice slides apply deck.pptx --ops ops.json --dry-run
teleoffice docs apply brief.docx --ops ops.json
```

‏`--dry-run` מדווח מה אצווה הייתה עושה ולא כותב דבר, וזו הדרך הזולה לבדוק מפרט לפני שהוא נופל. חלונית ה-AI של האפליקציה רצה בדיוק על אותן פעולות, ולכן כל מה שאתם יכולים לבקש ממנה אפשר גם לתסריט.

## Model Context Protocol

‏`teleoffice mcp` מגישה כל פקודה ככלי MCP, ו-`teleoffice mcp install <agent|all>` רושמת אותה בהגדרות של סוכן התכנון עצמו. ראו **חיבור סוכן תכנון** לצד הזה.

## מה שהפקודה אינה עושה

היא קוראת את הקובץ וכותבת אותו. היא אינה האפליקציה: אין חלון, וחלונית העדכון שבאפליקציה אינה חלה. כל מה שדורש את החלון — חלונית ה-AI, ביקורת האיכות על שקופית מרונדרת — חייב לחכות שתפתחו את הקובץ. ‏`teleoffice render` נותן לכם את הפיקסלים בלי זה, ו-`teleoffice slides` בודקת את הפריסה של מצגת בעצמה.
